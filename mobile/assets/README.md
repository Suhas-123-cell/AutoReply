# Native app assets

The React Native projects already contain the launcher assets:

- iOS: `ios/AutoReply/Images.xcassets/AppIcon.appiconset/App-Icon-1024x1024@1x.png`
  (1024 × 1024 App Store icon).
- Android: `android/app/src/main/res/mipmap-*/ic_launcher.webp` and
  `ic_launcher_round.webp` for launcher densities.
- Both platforms also contain splash resources in their native projects.

Replace these native assets in Xcode and Android Studio when final artwork is
approved. Check them on device and in the store upload preview.
